01 / QUESTIONResearch question

0 / 600

EcoBackfire researches the evidence, lets you review the assumptions, then runs the analysis.

Nothing is calculated until you confirm.

How to read the results. Findings are model-derived and conditional: they describe a simple rebound model, not a measured real system. Researched values are candidates found by automatic web search: a citation exists, nobody has checked it against the value. Values you override are your own assumptions, never external facts. Inputs without a source stay illustrative placeholders. evidence_insufficient means “the available evidence cannot yet confirm or challenge this” — it does not mean the finding is false.

    The engine executes, in this order:

    1. Analyzing candidates (discovery)
    2. Falsification
    3. Testing robustness
    4. Classification
    5. Generating reproducible artifacts
    6. Reproducibility re-run

    The engine does not report live per-stage progress, so this page does not pretend to; the real per-stage statuses and evaluation counts are shown with the results.
